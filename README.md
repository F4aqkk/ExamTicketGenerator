# ExamTicketGenerator

«Генератор экзаменационных билетов» (программа ExamTicket) — программа
для преподавателя: хранит банк вопросов, сама составляет из него
экзаменационные билеты и сохраняет их в файл.

## Что нужно для работы

- Windows 10 или Windows 11.
- Python 3.11 или новее — только для второго способа запуска
  (из исходного кода). Для готовой программы Python не нужен.
- Интернет — только чтобы скачать программу. Дальше она работает
  без интернета, все данные хранятся на этом компьютере.

## Как скачать и запустить

### Способ 1. Готовая программа (Python не нужен)

1. Скачайте архив
   [ExamTicket-1.1.0-windows.zip](https://github.com/F4aqkk/ExamTicketGenerator/releases/download/v1.1.0/ExamTicket-1.1.0-windows.zip)
   (около 62 МБ) со страницы
   [Releases](https://github.com/F4aqkk/ExamTicketGenerator/releases/tag/v1.1.0).
2. Распакуйте архив целиком, лучше всего в «Документы». Файл
   `ExamTicket.exe` работает только вместе с папкой `_internal`,
   которая лежит рядом, — запускать прямо из архива нельзя.
3. Дважды щёлкните **ExamTicket.exe**.

### Способ 2. Из исходного кода (нужен Python)

1. Установите Python: <https://www.python.org/downloads/> (кнопка
   «Download Python»). В первом окне установки поставьте галочку
   **Add python.exe to PATH**.
2. Скачайте исходный код:
   [архив ZIP](https://github.com/F4aqkk/ExamTicketGenerator/archive/refs/heads/main.zip)
   (или на этой странице: зелёная кнопка **Code** → **Download ZIP**)
   и распакуйте его.
3. В распакованной папке дважды щёлкните файл **start.bat**.

При первом запуске `start.bat` сам ставит нужные библиотеки (нужен
интернет, это несколько минут) и создаёт базу с примерами вопросов.
В следующие разы программа открывается сразу. Файл `start.bat` — это
второй способ: для готовой программы из Releases он не нужен.

Если Windows спросит, запускать ли файл, нажмите «Запустить»
(или «Подробнее» → «Выполнить в любом случае»).

## Где программа хранит данные

Банк вопросов (файл `exam_tickets.db`) и настройки (`settings.json`)
лежат в папке самой программы — рядом с `ExamTicket.exe` или в папке
проекта.

Если записывать в эту папку нельзя (папка оказалась на диске только
для чтения или в защищённом месте вроде `Program Files`), программа
не падает, а сама переходит на запасную папку
`%LOCALAPPDATA%\ExamTicket` — это `C:\Users\Имя\AppData\Local\ExamTicket`.
Готовый банк вопросов при этом один раз копируется туда, чтобы ничего
не потерялось. Открыть эту папку: Win+R, вписать
`%LOCALAPPDATA%\ExamTicket`, нажать Enter.

## Что умеет программа

- **Банк вопросов**: темы, три уровня сложности, тип задания, теги,
  ответ к вопросу; поиск и фильтры; до 6000 вопросов.
- **Генератор**: до 100 билетов за раз, в каждом заданное число лёгких,
  средних и сложных вопросов из выбранных тем; правила «не повторять
  вопросы» и «разные темы в билете»; предпросмотр билетов.
- **Экспорт** билетов в DOCX, PDF, XLSX и TXT, с ответами или без.
- **Импорт и экспорт банка вопросов** в тех же форматах.
- **История**: сохранённые генерации можно открыть или удалить.
- **Настройки**: шапка документа (организация, дисциплина,
  преподаватель) и формат экспорта по умолчанию.

## Как оформить файл для импорта вопросов

Вопросы загружаются в разделе «Банк вопросов» кнопкой **Импорт**.
Подходят файлы XLSX, TXT, DOCX и PDF.

Самый простой способ получить образец: нажмите **Экспорт банка**.
Программа сохранит файл в нужном виде — его можно править и загружать
обратно.

### Таблица XLSX

В первой строке — названия столбцов, дальше по одному вопросу
в строке:

| Тема | Сложность | Тип задания | Вопрос | Ответ | Теги |
|---|---|---|---|---|---|
| SQL | лёгкий | Теория | Что делает SELECT? | Выбирает строки из таблицы. | запросы, основы |
| Git | 2 | Практика | Создайте ветку и переключитесь на неё. | | ветки |

Столбцы могут стоять в любом порядке. Обязателен только столбец
«Вопрос».

### Текст: TXT и DOCX

Каждый вопрос записывается строками «Поле: значение». Между вопросами —
пустая строка:

```
Тема: SQL
Сложность: лёгкий
Тип задания: Теория
Теги: запросы, основы
Вопрос: Что делает SELECT?
Ответ: Выбирает строки из таблицы.

Тема: Git
Сложность: 2
Вопрос: Создайте ветку и переключитесь на неё.
```

Длинный текст можно переносить на следующую строку: строка без
названия поля продолжает предыдущее поле. В Word вопросы пишутся
обычными абзацами, таблицы Word не читаются. Файл TXT подходит
из обычного Блокнота.

### PDF

PDF читается, если в нём настоящий текст в том же виде, что в TXT, —
например, файл, сохранённый кнопкой «Экспорт банка». Сканы
и фотографии не читаются.

### Правила для полей

| Поле | Что писать | Если не указано |
|---|---|---|
| Вопрос | Текст вопроса | Запись пропускается |
| Тема | Название темы; новой темы ещё нет в банке — она создастся | Вопрос попадёт в тему «Без темы» |
| Сложность | Цифра 1, 2, 3 или слово: лёгкий, средний, сложный (в любой форме: «лёгкая», «Средние») | Вопрос добавится с отметкой «сложность не задана» |
| Тип задания | «Теория» или «Практика» | «Теория» |
| Теги | Через запятую, можно со знаком # в начале | Вопрос без тегов |
| Ответ | Текст ответа | Вопрос без ответа |

- Если сложность написана другим словом (например, «трудный»), она
  тоже считается незаданной. Такие вопросы не попадают в билеты, пока
  вы не укажете сложность: в банке их показывает фильтр «Без сложности».
- Вопрос, который уже есть в банке (тот же текст в той же теме), второй
  раз не добавляется.
- После импорта программа показывает, сколько вопросов добавлено
  и сколько пропущено.

## Если что-то не работает

| Что случилось | Что делать |
|---|---|
| `start.bat` пишет «Python не найден» | Установите Python с галочкой **Add python.exe to PATH** и запустите `start.bat` ещё раз |
| «Не удалось установить библиотеки» | Проверьте интернет и запустите `start.bat` ещё раз |
| Windows пишет «Система Windows защитила ваш компьютер» | Нажмите «Подробнее» → «Выполнить в любом случае» |
| Банк вопросов вдруг пустой | Запускайте программу через `start.bat` из её папки: база — файл `exam_tickets.db` в этой папке |
| `ExamTicket.exe` не запускается или сразу закрывается | Распакуйте архив целиком: рядом с exe должна лежать папка `_internal` |
| Раньше было «readonly database» или «Permission denied … settings.json» | Теперь программа сама переходит на папку `%LOCALAPPDATA%\ExamTicket`, данные там. Чтобы всё лежало в одной папке, перенесите папку программы в «Документы» |
| «Импорт не выполнен» или «В файле не найдено ни одного вопроса» | Оформите файл по образцу выше или возьмите образец кнопкой **Экспорт банка** |
| После импорта «Сложность не распознана» | Найдите вопросы фильтром «Без сложности» и укажите сложность |
| «Не удалось записать файл» | Закройте этот файл в Word или Excel либо сохраните в другую папку |
| «Не хватает … вопросов» в генераторе | Отметьте больше тем, уменьшите число вопросов этой сложности или добавьте вопросы |
| Нужно перенести вопросы на другой компьютер | «Настройки» → «Сохранить копию», на новом компьютере — «Восстановить» |
| Вышла новая версия, банк терять нельзя | Перед обновлением: «Настройки» → «Сохранить копию», в новой версии — «Восстановить». Или скопируйте `exam_tickets.db` и `settings.json` в новую папку |
| «Часть вопросов повторится между билетами.» | Это предупреждение: отметьте больше тем, уменьшите число билетов или добавьте вопросы |
| Вопрос никогда не попадает в билеты | У него не задана сложность: фильтр «Без сложности» в банке вопросов |

Полный список сообщений программы и типовых проблем — в руководстве
оператора ([docs/operator.rst](docs/operator.rst)).
