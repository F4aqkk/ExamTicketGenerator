# ExamTicketGenerator

«Генератор экзаменационных билетов» (программа ExamTicket) — программа
для преподавателя: хранит банк вопросов, сама составляет из него
экзаменационные билеты и сохраняет их в файл.

## Как скачать и запустить

1. Установите Python: <https://www.python.org/downloads/> (кнопка
   «Download Python»). В первом окне установки поставьте галочку
   **Add python.exe to PATH**.
2. Скачайте программу:
   [архив ZIP](https://github.com/F4aqkk/ExamTicketGenerator/archive/refs/heads/main.zip)
   (или на этой странице: зелёная кнопка **Code** → **Download ZIP**)
   и распакуйте его.
3. В распакованной папке дважды щёлкните файл **start.bat**.

При первом запуске `start.bat` сам ставит нужные библиотеки (нужен
интернет, это несколько минут) и создаёт базу с примерами вопросов.
В следующие разы программа открывается сразу.

Если Windows спросит, запускать ли файл, нажмите «Запустить»
(или «Подробнее» → «Выполнить в любом случае»).

## Что умеет программа

- **Банк вопросов**: темы, три уровня сложности, тип задания, теги,
  ответ к вопросу; поиск и фильтры; до 6000 вопросов.
- **Генератор**: до 100 билетов за раз, в каждом заданное число лёгких,
  средних и сложных вопросов из выбранных тем; правила «не повторять
  вопросы» и «разные темы в билете»; предпросмотр билетов.
- **Экспорт** билетов в DOCX, PDF, XLSX и TXT, с ответами или без.
- **Импорт и экспорт банка вопросов** в тех же форматах.
- **История**: сохранённые генерации можно открыть или удалить.
- **Настройки**: шапка документа (организация, дисциплина,
  преподаватель) и формат экспорта по умолчанию.

## Как оформить файл для импорта вопросов

Вопросы загружаются в разделе «Банк вопросов» кнопкой **Импорт**.
Подходят файлы XLSX, TXT, DOCX и PDF.

Самый простой способ получить образец: нажмите **Экспорт банка**.
Программа сохранит файл в нужном виде — его можно править и загружать
обратно.

### Таблица XLSX

В первой строке — названия столбцов, дальше по одному вопросу
в строке:

| Тема | Сложность | Тип задания | Вопрос | Ответ | Теги |
|---|---|---|---|---|---|
| SQL | лёгкий | Теория | Что делает SELECT? | Выбирает строки из таблицы. | запросы, основы |
| Git | 2 | Практика | Создайте ветку и переключитесь на неё. | | ветки |

Столбцы могут стоять в любом порядке. Обязателен только столбец
«Вопрос».

### Текст: TXT и DOCX

Каждый вопрос записывается строками «Поле: значение». Между вопросами —
пустая строка:

```
Тема: SQL
Сложность: лёгкий
Тип задания: Теория
Теги: запросы, основы
Вопрос: Что делает SELECT?
Ответ: Выбирает строки из таблицы.

Тема: Git
Сложность: 2
Вопрос: Создайте ветку и переключитесь на неё.
```

Длинный текст можно переносить на следующую строку: строка без
названия поля продолжает предыдущее поле. В Word вопросы пишутся
обычными абзацами, таблицы Word не читаются. Файл TXT подходит
из обычного Блокнота.

### PDF

PDF читается, если в нём настоящий текст в том же виде, что в TXT, —
например, файл, сохранённый кнопкой «Экспорт банка». Сканы
и фотографии не читаются.

### Правила для полей

| Поле | Что писать | Если не указано |
|---|---|---|
| Вопрос | Текст вопроса | Запись пропускается |
| Тема | Название темы; новой темы ещё нет в банке — она создастся | Вопрос попадёт в тему «Без темы» |
| Сложность | Цифра 1, 2, 3 или слово: лёгкий, средний, сложный (в любой форме: «лёгкая», «Средние») | Вопрос добавится с отметкой «сложность не задана» |
| Тип задания | «Теория» или «Практика» | «Теория» |
| Теги | Через запятую, можно со знаком # в начале | Вопрос без тегов |
| Ответ | Текст ответа | Вопрос без ответа |

- Если сложность написана другим словом (например, «трудный»), она
  тоже считается незаданной. Такие вопросы не попадают в билеты, пока
  вы не укажете сложность: в банке их показывает фильтр «Без сложности».
- Вопрос, который уже есть в банке (тот же текст в той же теме), второй
  раз не добавляется.
- После импорта программа показывает, сколько вопросов добавлено
  и сколько пропущено.
