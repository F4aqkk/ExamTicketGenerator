Описание применения
===================

Документ составлен по ГОСТ 19.502-78 «Описание применения. Требования
к содержанию и оформлению».

Назначение программы
--------------------

«ExamTicket» — настольная программа для преподавателя. Она заменяет
ручное составление экзаменационных билетов и контрольных вариантов:
преподаватель один раз заносит вопросы в банк, а дальше программа
сама набирает из них билеты нужного состава.

Возможности программы:

* банк вопросов: тема, сложность (лёгкий, средний, сложный), тип
  задания (теория или практика), теги, текст вопроса и ответ; поиск
  и фильтры по теме, тегу и сложности;
* составление билетов: название работы, количество билетов,
  количество лёгких, средних и сложных вопросов в одном билете,
  выбор тем; правила «не повторять вопросы» и «разные темы в билете»;
* предпросмотр билетов до сохранения;
* экспорт билетов в DOCX, PDF, XLSX и TXT, с ответами или без;
* импорт и экспорт всего банка вопросов в тех же форматах (так же
  делается резервная копия банка);
* история: сохранённые наборы билетов можно открыть снова или удалить;
* настройки шапки документа (образовательная организация,
  дисциплина, преподаватель) и формата экспорта по умолчанию.

Основные характеристики и ограничения:

* банк рассчитан на 6000 вопросов;
* за один раз составляется от 1 до 100 билетов;
* в одном билете — до 20 вопросов каждой сложности;
* программа работает на одном компьютере, без интернета и без входа
  по паролю (один пользователь);
* в билет попадают только вопросы с указанной сложностью.

Условия применения
------------------

Технические средства:

* компьютер с Windows 10 или Windows 11 (64 бит); отдельных требований
  к процессору и памяти техническое задание не ставит;
* место на диске для папки программы с библиотеками и для файлов
  с билетами;
* поддерживается масштаб экрана Windows 100, 125, 150 и 175 %.

Программные средства:

* для готовой сборки (папка с файлом ``ExamTicket.exe``) ничего
  устанавливать не нужно;
* для запуска из исходного кода нужен Python 3.11 или новее (проверено
  на Python 3.14); библиотеки ставятся автоматически файлом
  ``start.bat`` из списка ``requirements.txt``. Интернет нужен только
  при первом запуске, чтобы скачать библиотеки.

Для экспорта в PDF нужен шрифт с русскими буквами. Программа берёт
Times New Roman из папки шрифтов Windows, а если его нет — Arial,
Liberation Serif или DejaVu Serif.

Описание задачи
---------------

Задача: из банка вопросов составить заданное число билетов так, чтобы
в каждом билете было нужное количество вопросов каждой сложности
из выбранных тем, вопросы внутри одного билета не повторялись,
а между билетами повторялись как можно реже.

Метод решения (класс ``TicketGenerator``):

#. Для каждой сложности из банка выбираются вопросы этой сложности
   из выбранных тем.
#. Если таких вопросов меньше, чем нужно в один билет, билеты
   не составляются, и программа сообщает, каких вопросов не хватает.
#. Вопросы перемешиваются и ставятся в очередь. Каждый билет по очереди
   берёт из неё нужное количество вопросов. Когда очередь кончается,
   вопросы перемешиваются заново — только тогда вопрос может
   встретиться второй раз (в другом билете). Если правило
   «не повторять вопросы» выключено, каждый билет набирается из всех
   вопросов заново.
#. Если включено правило «разные темы в билете», из очереди сначала
   берутся вопросы тех тем, которых в этом билете ещё нет.
#. Готовые билеты вместе с названием работы и датой записываются
   в базу данных одной транзакцией: либо сохраняется весь набор,
   либо ничего.

Входные и выходные данные
-------------------------

Входные данные:

* вопросы, введённые вручную в форме «Новый вопрос»;
* файлы для импорта вопросов: таблица XLSX (столбцы «Тема»,
  «Сложность», «Тип задания», «Вопрос», «Ответ», «Теги»), текстовые
  файлы TXT и DOCX (строки вида «Поле: значение», вопросы разделены
  пустой строкой), PDF с текстом в том же виде. Подробно формат описан
  в файле ``README.md``;
* параметры составления билетов на экране «Генератор»;
* настройки на экране «Настройки».

Выходные данные:

* файлы с билетами DOCX, PDF, TXT (каждый билет на своей странице:
  организация, название работы, дисциплина, «БИЛЕТ № N», вопросы
  с подписью «тема · сложность», преподаватель; по желанию —
  ответы) и таблица XLSX;
* файл с банком вопросов (резервная копия) в формате DOCX, PDF, XLSX
  или TXT; его можно загрузить обратно импортом.

Где хранятся данные:

* ``exam_tickets.db`` — база данных SQLite (вопросы, темы, теги,
  наборы билетов);
* ``settings.json`` — настройки.

Оба файла лежат рядом с ``ExamTicket.exe``, а при запуске из кода — в папке
проекта.
