Документация программы «ExamTicket»
====================================

**Генератор экзаменационных билетов.** Версия 1.0.

Документация оформлена по стандартам Единой системы программной
документации (ЕСПД): общие требования к документам — ГОСТ 19.105-78,
состав разделов каждого документа — по стандарту, указанному
в его заголовке.

Аннотация
---------

Программа «ExamTicket» помогает преподавателю составлять
экзаменационные билеты. Она хранит банк вопросов (до 6000 записей)
с темами, сложностью, типом задания, тегами и ответами, сама составляет
до 100 билетов за раз по заданному составу и сохраняет их в файлы
DOCX, PDF, XLSX и TXT.

В документацию входят:

* **Описание применения** (ГОСТ 19.502-78) — для чего нужна программа,
  какую задачу она решает, какие данные принимает и выдаёт.
* **Руководство оператора** (ГОСТ 19.505-79) — руководство пользователя:
  как запустить программу, как с ней работать и что делать, если
  появилось сообщение об ошибке.
* **Руководство системного программиста** (ГОСТ 19.503-79) — руководство
  разработчика: устройство программы, настройка, сборка, проверка
  и порядок передачи проекта другому разработчику.
* **Отчёт о тестировании** — виды тестов, покрытие кода, проверка
  требований ТЗ, найденные и исправленные ошибки.
* **Описание программного кода** — собрано автоматически из строк
  документации (docstrings) модулей, классов и функций.
* **Бэклог продукта** — что можно улучшить в следующих версиях.
* **Лист регистрации изменений** — история изменений документации.
